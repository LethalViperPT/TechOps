**Como fazer:** pede a um colega (ou troca de projeto com outro formando) para
usar a aplicação AutoCare sem qualquer explicação prévia. Observa em silêncio,
sem ajudar, e regista o que aconteceu. No fim, aplica as correções razoáveis
que o tempo permitir.

## Nota

Como o `Main.java` ainda não tem um menu/interface interativa real (isso só
foi pedido a partir da Aula 4 como "ponto de entrada", sem ecrã), o teste de
usabilidade mais realista, nesta fase, é pedir ao colega para ler o código
de `Main.java` e tentar prever o que cada bloco faz, ou testar diretamente
os métodos dos serviços a partir de uma pequena consola/menu que construas
para o efeito. Se preferires, digo-te como construir rapidamente um menu de
texto simples (`Scanner` + `switch`) só para tornar este teste mais realista.
